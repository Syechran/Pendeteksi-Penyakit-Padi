## 🚀 Cara Menjalankan Aplikasi di Komputer Lokal

Proyek ini sudah dilengkapi dengan skrip otomatisasi. Kamu tidak perlu melakukan instalasi manual satu per satu.

### Langkah Mudah:
1. Buka Terminal / Command Prompt tepat di dalam direktori root hasil clone (`Pendeteksi-Penyakit-Padi`).
2. Jalankan perintah sesuai dengan Sistem Operasi yang kamu gunakan:

* **Pengguna Windows:**
  Cukup klik dua kali file `jalankan-windows.bat` atau ketik di Terminal:
  ```bash
  jalankan-windows.bat
